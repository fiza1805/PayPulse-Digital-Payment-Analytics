# 💳 PayPulse — Digital Payment Analytics Dashboard

An interactive data analytics dashboard built using Python, SQL, Pandas, Streamlit, and Plotly to explore India's digital payment trends using the publicly available PhonePe Pulse dataset.

## Project Overview

PayPulse analyzes aggregated transaction statistics across Indian states and union territories, helping users explore transaction volumes, monetary values, quarterly growth, and geographic trends.

## Key Features

- Interactive year and State / UT filters
- Total transactions and transaction value KPIs
- Average transaction value analysis
- Quarterly transaction trends
- Quarter-over-quarter growth analysis
- Top 10 states by transaction volume
- Historical state leadership rankings
- Automatically generated business insights

## Technology Stack

**Languages:** Python, SQL

**Libraries:** Pandas, Plotly, Streamlit

**Database:** MySQL

**Development Tools:** VS Code, MySQL Workbench, Git, GitHub

## Data Source

PhonePe Pulse public dataset:

https://github.com/PhonePe/pulse

The dashboard uses aggregated state-level transaction data extracted from the published JSON files. It does not contain individual customer transactions or personally identifiable payment records.

## Data Pipeline

1. Extract transaction statistics from PhonePe Pulse JSON files.
2. Transform the data into a structured CSV using Python and Pandas.
3. Load the processed data into MySQL.
4. Analyze transaction trends using SQL.
5. Visualize the data in Streamlit using Plotly.

The dashboard currently reads the processed CSV generated by the pipeline. MySQL is used for storing and validating the analytical dataset.

## Dataset Summary

- 1,224 state-quarter records
- 36 states and union territories
- Coverage: 2018 Q1–2026 Q2
- 2026 is a partial year in the current dataset

## Key Findings

- Maharashtra recorded the highest transaction volume in 2025.
- Karnataka led transaction volume in 2019, 2020, 2021, and 2023.
- Transaction volume increased in every quarter of 2025.
- Q3 2025 recorded 6.02% quarter-over-quarter transaction growth.

## Running the Dashboard Locally

Install the required Python packages:

```bash
python -m pip install streamlit pandas plotly
```

Generate the processed transaction data using `extract_state_transactions.py`, with the PhonePe Pulse dataset available in the expected local folder.

Launch the dashboard:

```bash
python -m streamlit run dashboard.py
```

Open `http://localhost:8501` in your browser.

## Limitations

The results describe the published PhonePe Pulse dataset and should not be interpreted as the complete Indian UPI ecosystem.

The dataset contains aggregated transaction statistics rather than individual transaction records. It does not support customer-level or merchant-level fraud and failure analysis.
